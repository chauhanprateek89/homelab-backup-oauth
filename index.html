homelab-backup

homelab-backup is a private tool that copies encrypted backups of one person's home server to that person's own Google Drive. It runs on a schedule on the server, and its backups can be restored if the server fails.

It only uses the drive.file permission, so it can see only the files it created. It can't read anything else in the Drive.

It is for the owner's personal use and is not offered to anyone else.
