homelab-backup privacy policy

homelab-backup is a private tool used only by its owner, on their own Google account.

Data it accesses

It accesses only the files it creates in the owner's Google Drive, through the drive.file permission. It can't see any other files in that Drive, and it doesn't access any other person's data.

How the data is used and stored

Backups are encrypted on the owner's server before upload, and are stored in the owner's Google Drive. They are used only to restore that server. The Google sign-in token is stored only on that server.

Sharing

No data is sold, or shared with or sent to anyone else. There is no advertising and no analytics.

Use of data received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be revoked at any time from the Google account permissions page.

Contact

Through the owner's GitHub profile.
